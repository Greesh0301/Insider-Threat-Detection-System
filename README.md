# 🛡️ Insider Threat Detection System

## Overview

The **Insider Threat Detection System** is a web-based cybersecurity application developed using **Python Flask** to monitor employee activities and detect potential insider threats within an organization. The system records user actions, analyzes suspicious behavior using predefined security rules, and generates real-time alerts to help administrators identify and respond to security incidents.

It provides a centralized dashboard for monitoring employee activities, viewing alerts, tracking risk scores, and generating security reports, enabling organizations to strengthen their internal security posture and reduce insider risks.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Greesh0301/Insider-Threat-Detection-System.git
```

### 2. Navigate to the Project Directory

```bash
cd Insider-Threat-Detection-System
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open the Application

Visit the following URL in your web browser:

```text
http://127.0.0.1:5000
```
